# Muhtasim Ibteda Shochcho

## About

I build secure, production-grade systems for the financial sector by day and study how language models work by night. At Bangladesh Finance PLC I design and ship the software behind the company's move from paper to paperless: digital onboarding, document tracking, audit automation, and an in-house security operations platform. As an applied NLP researcher at CCDS, Independent University, Bangladesh, I work on LLM evaluation for Bangla, AI tutoring, and educational NLP.

## Research Statement

I am passionate about making Large Language Models safer, more interpretable, and culturally inclusive. My research focuses on mechanistic interpretability to understand how LLMs process information, with applications in educational AI and cybersecurity. I aim to bridge the gap between cutting-edge NLP research and real-world deployment, particularly for low-resource languages like Bangla. Running a security operations platform in production has also given me a direct view of where AI can help defenders, which shapes my interest in small language models for intrusion detection and synthetic traffic generation.

### AEGIS: Security Operations Platform
- id: off-1
- featured: true
- category: Cybersecurity
- role: Architect & Lead Developer
- period: July 2026 – Present
- status: Pilot
- description: An open-source security operations platform built on Wazuh for Bangladesh Finance PLC. AEGIS brings endpoint telemetry, YARA malware scanning, two perimeter firewalls, and Microsoft 365 audit logs into one pipeline, then turns raw alerts into scored, explainable incidents an analyst can act on.
- techStack: Wazuh, YARA, Python, PostgreSQL, FortiGate syslog, Palo Alto PAN-OS, Microsoft 365 Management API, systemd, Linux
- highlights:
  - Ingests four live telemetry sources: Wazuh/Windows endpoint events, YARA file scans, FortiGate and Palo Alto firewall logs, and Microsoft 365 sign-in audit events
  - Built the Fusion Triage Engine, which normalizes every source into a unified security record, persists it to an append-only PostgreSQL ledger, and runs every five minutes
  - Correlation engine groups related events into incident candidates by user session, filtering out machine and service accounts
  - Versioned, replayable risk scoring (0-100) weighs activity diversity, source diversity, severity, and burst compression, with damping for high-volume noise; high-risk incidents are written back to the Wazuh dashboard
  - Explainable by construction, with no LLM or GPU dependency
  - High-level design mapped to the Bangladesh Bank ICT Security Guideline v4.0
- impact: Processed hundreds of thousands of events in the office pilot and surfaced real, previously unseen security findings for the network team.
